# How I would improve MedChron next

These follow from how the product is built today.

Measure citation coverage per document type, so a drop in cited facts for, say, pharmacy records is visible before an attorney notices it. Extend the replay evaluation from medications to every extraction stage, so no prompt change ships without a before-and-after on real records. Track cost and turnaround per case and show both to the firm, because a chronology that arrives in hours is only useful if the price per case is predictable. Give Chi a way to show the exact page image beside each cited fact, so trust does not depend on the reader opening the file. Keep the deterministic guards growing ahead of the model: every class of duplicate the team finds becomes a rule, not a prompt tweak.
